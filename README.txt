MONDI AI 2.9
Consulta README.md para funciones, límites y preparación de actualizaciones.

Aplicación Android independiente de CifraChat. Paquete com.mondi.ai, versionCode 30. Incluye chat API, voz, herramientas Android, editor local, terminal sin root y guía de Termux/Ubuntu externo. Requiere endpoint/modelo/clave de un proveedor para generar respuestas. No usa Google Colab.

Para actualizar encima de la instalación y conservar datos, cada APK de publicación debe llevar la misma firma persistente. Consulta ACTUALIZACIONES.md.
